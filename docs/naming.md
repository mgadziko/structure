# Naming Notes

Structure remains the development name for the app, repository, prototype, and internal documentation unless deliberately changed later.

This file preserves possible future product names and the reasoning behind them without destabilizing development naming.

## Current Development Name

### Structure

Rationale:

- plain, strong, and descriptive
- points to what the app provides after capture
- suggests durability and order without requiring a rigid schema up front
- works well as a development name while the product takes shape

Status: active development name.

## Back-Pocket Names

### Connections

Rationale:

- points to what the user creates at a visceral level
- emphasizes relationships among Entries, Items, Attributes, Categories, people, dates, events, and ideas
- complements Structure: the user creates connections; the app provides structure around them

Status: possible future product name, not current development name.
